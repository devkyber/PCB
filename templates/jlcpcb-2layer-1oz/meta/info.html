JLCPCB 2-layer / 1 oz baseline

KiCad 10 starting settings for new FR4 boards: two layers, 1.6 mm thickness, 35 um copper per face, green mask, white legend and tented vias. Add the circuit and a closed board outline. KiCad creates the empty schematic automatically.

In PCB Editor, use File > Board Setup. Existing projects may selectively use Import Settings from Another Board, choosing this template's .kicad_pcb. Review imported constraints and custom rules before accepting them.

These are workspace defaults, some deliberately larger than factory minima. The custom rules also flag thin nonzero silkscreen strokes from imported footprints. Setting defaults does not redraw existing footprint graphics.

Scope: 2-layer, 1 oz, green mask only. Check another profile for 2 oz, other mask colours, multilayer, high voltage, HDI or special processes. Set power-net widths from current and temperature requirements. Component spacing, paste and thermal-pad design, slot aspect ratios, routed cutouts, fiducials/rails, mechanical fit, part stock and rotations still require review. Choose and record surface finish per project; this template does not select it at checkout.

Native DRC checks geometry; it does not establish circuit performance or grant fabrication approval. Run the workspace review/release workflow on each project.
